Branding

Use the Branding page to create and edit the basic look and feel of your Cloud Portal site.

Available fields are:

Cloud Name – enter the name of the Cloud Portal. Contents of this field display as the title on the portal landing page.

Skin – choose the default color for accent text and line graphics on your portal. Note that changing the skin requires a forced update.

VMS Name – enter the name of your VMS product. Contents of this field are displayed as the product name for downloads, e.x. in the download {{VMS_Name}} shortcut footer. Avoid using more than 20 characters.

Cloud tab name – enter a name for the Cloud Portal that will display on the tab of the Desktop client.

Support Link – enter the short form /content/support to use the embedded CMS "Support" page, or enter a complete URL if you prefer to use another page such as your company's existing support page (for example, https://support.networkoptix.com/hc/en-us/).

Support Link Text – enter the text to be shown as the support link in emails.

Privacy Policy link – enter a complete URL to link to an existing privacy policy page, or enter the short form (ex. /privacy-policy/) to use the embedded "Privacy Policy": (https://{{CLOUD_ADDRESS}}/content/privacy page.)

Company web site – enter the full link for your company's main web site.

Company Name – enter the company name.

Copyright Year – enter year the page was copyrighted.

Client Protocol – select the URL protocol for calling native clients from a browser. If you are unsure of the proper choice do not change this value. Changing it may negatively affect the interaction between the Cloud Portal and Desktop client

IOS application ID – select an App ID for the iOS mobile application. Do not change this value unless you are sure it is necessary. Changing it can cause issues when interacting with the mobile client.

IOS application link – select a link for the iOS application in the Apple AppStore.

Android application link – enter a link for the Android application in Google Play.

Mail from - name – enter a sender name for emails coming from the Cloud Portal.

Mail from - email – enter a sender email address for emails coming from the Cloud Portal. Note that this entry is case sensitive and must be verified by Amazon. Contact support if you need assistance with this.

Favicon – upload a favicon image for Cloud Portal tabs. The image must be .ico format.

Portal header logo – upload a logo that will display on every page. The logo must be .png format and have a height of 64 pixels.

Email logo – upload a logo that will be used in outgoing emails. The logo must be .png format. Width must be 32 to 240 pixels and height must be 32 to 64 pixels.
