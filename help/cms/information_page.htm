Information

Use this page to enter general information about the integration.

Available fields are:

Integration name – name of the integration.

Logo – logo for the integration.

Description – general information about the integration.

Type (Category) – category the integration falls under.

Tags – keywords describing the integration.

Company Name – name of the company.

Company Website – link to the company's website.

Company Privacy Policy – link to the company's privacy policy.

Terms of Use for the Integration – link to the terms of use for the integration.
