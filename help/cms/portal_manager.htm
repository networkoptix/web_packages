Portal Manager

A Portal Manager deals with both Cloud Portals and Integrations. They are able to edit, review, and publish Cloud Portal content, as well as review and publish content for Integrations. Portal Managers have the final say when it comes to updating or adding new content. This includes reviewing changes made by Integration Developers or Content Managers.

Portal managers see all previews available in the current cloud customization.

See "Cloud Users" and "Asset Management" for more details on the available actions.

Note: To change Developer and Content Manager permissions, you will need to contact Network Optix.
