# nx-components

This library contains the new component library. It's buildable and publishable. Buildable means that when used within
the monorepo the build process will be faster since compiled components can be cached and incrementally built. Publishable
means that the library can be packaged and published to npm or artifactory for use with either other internal projects
or be made available for partners.

## Public API

All components should be exported from `src/index.ts` in the root of the library. This is the public API for the library;
components shouldn't be imported directly from `src/libs/*` or else they won't be pre-compiled.

## Usage

To use the component library within the monorepo import from the `nx-components` path like this
`import { NxExampleComponent } from 'nx-components'`.

To use the component library from the published package from outside the monorepo import from the `@networkoptix/nx-components`
namespace like this `import { NxExampleComponent } from '@networkoptix/nx-components'`.

## Conventions

- All components should be prefixed with `nx`.
- **Future** - All web components should be prefixed with `nxwc` to prevent conflicts with the Angular components.
- All components should be exported from `src/index.ts`.
- Components should be compatible with zoneless change detection so should use OnPush change detection strategy and
use reactive primitives such as signals and observables for properties that can change.
- Documentation is automatically generated by compodoc so all components should have jsdoc comments for the component
itself and for the public api for the component such as inputs and outputs.
- All components should have at least base stories.
- Components shouldn't rely on any global styling.

## Component Styling Reset

Sometimes application styling could leak into the component library. We use css layers to prevent unintended leaking
into the component styles.

### Within the application
To prevent global styles from leaking into library wrap your styles in an nxglobal css layer `@layer nxglobal {...styles}`.

## Running tasks

Run `nx run nx-components:storybook` to run storybook.

Run `nx run nx-components:test` to execute the unit tests.

Run `nx run nx-components:lint` to execute linting.

Run `nx run nx-components:build` to build angular component library.
